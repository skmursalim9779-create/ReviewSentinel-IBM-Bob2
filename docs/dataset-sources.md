# Dataset and data sources

## Bundled demo
`sample_repo/user_service.py` is synthetic code written specifically for this demo. It contains intentionally planted, non-working examples of review issues. It is not client data, company-confidential data, personal information, or social-media data.

## Optional GitHub demo mode
The web demo can scan a public GitHub repository supplied by the user. The repository URL and the default branch metadata are fetched at runtime; no GitHub credentials are stored by ReviewSentinel. Use only repositories whose contents and licenses permit the intended use.

When demonstrating an external repository, record the repository URL and its license/terms here before submission.
