# Submission checklist

## Hackathon requirements to verify before submitting

- [ ] IBM Bob IDE was genuinely used as a core part of the build/iteration workflow.
- [ ] For every Bob task related to the submission, the required task-session summary screenshot is stored in `bob_sessions/`.
- [ ] Exported Bob task history is stored when required by the guide.
- [ ] The repository contains no API keys, credentials, private/client data, or prohibited data sources.
- [ ] Any external data source used for the demo is listed in `docs/dataset-sources.md` with source/license/terms.
- [ ] A working online prototype is available for judges.
- [ ] The public GitHub repository is clean and understandable.
- [ ] Demo video and pitch deck are prepared according to the platform's submission form.
- [ ] Impact claims use measurements you actually performed.

## Evidence that must come from the real build

Do not add fake screenshots, fake Bob task histories, fake benchmark numbers, or fake deployment links. This repository provides placeholders and tooling; the participant must supply the actual evidence.
